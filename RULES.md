# Rules

A running set of process rules, added only once something has actually proven itself through real trades, not assumed in advance. Each rule notes which week/trade it came from.

## Discretionary

- **Check the earnings/catalyst calendar before every entry.** (Added Week 31 — AAPL entered the day before a Q3 earnings report without this being the deciding factor in timing; the report turned out strong, but the position still carried avoidable, unaccounted-for event risk.)
